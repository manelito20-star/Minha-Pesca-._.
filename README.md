# 🎣 Minha Pesca - O Guia Definitivo para Pescadores

O **Minha Pesca** é uma aplicação móvel moderna desenvolvida em **Jetpack Compose** para Android, criada para ajudar pescadores amadores e profissionais a planear as suas jornadas de pesca com precisão e facilidade.

---

## 🌟 Funcionalidades Principais

* **🗺️ Mapa Interativo de Pesca**: 
  * Consulta centenas de pesqueiros, rampas de barcos e lojas de isco em Portugal pré-carregados na aplicação.
  * Visualização de zonas de pesca proibidas (ex: reservas marinhas e áreas protegidas).
  * Integração com **Google Maps** e rotas instantâneas de navegação via **Waze** ou **Google Maps**.
* **🌐 Base de Dados Comunitária (Partilha na Nuvem)**:
  * **O grande destaque da app!** Os utilizadores podem partilhar os seus pontos de pesca privados diretamente com a comunidade através de uma base de dados em tempo real (**Firebase Firestore**).
  * Explora no mapa os pontos adicionados por outros pescadores.
  * **Sistema de Reporte Inteligente**: Podes reportar pontos incorretos ou falsos. A aplicação gere automaticamente as denúncias, removendo pontos da nuvem quando atingem o limite de reportes para manter o mapa sempre fiável.
* **📍 Gestão de Pontos Privados e Predefinidos**:
  * Adiciona os teus próprios pesqueiros no mapa (com seleção de tipo: pesqueiro, rampa ou loja de isco).
  * **Edita ou elimina** qualquer ponto (tanto os teus pontos privados como os pontos predefinidos da app) para manteres o teu mapa sempre correto.
  * Partilha os teus pontos com amigos através de códigos JSON ou por partilha pública na comunidade.
* **🌊 Marés e Condições**: Informações meteorológicas e marítimas essenciais.
* **🌙 Fases da Lua**: Calendário lunar para otimizar as capturas.
* **🪢 Nós de Pesca**: Guia visual com os principais nós de pesca.
* **🐟 Espécies e Técnicas**: Conhece as espécies e montagens recomendadas.

---

## 🚀 Como Utilizar

1. **Explorar o Mapa**: Abre o ecrã do mapa para ver todos os pesqueiros disponíveis. Clica em qualquer marcador para ver os detalhes, navegar via GPS ou editar/reportar.
2. **Adicionar e Partilhar**: Mantém premido qualquer local no mapa para adicionar um novo ponto privado. Podes partilhá-lo com a comunidade na nuvem com um clique.
3. **Comunidade**: Os pontos partilhados por outros pescadores aparecem automaticamente no mapa. Ajuda a manter a qualidade reportando incorreções se detetares algum erro.

## 🛠️ Tecnologias Utilizadas
* **Jetpack Compose & Material 3**: Interface de utilizador moderna e adaptativa.
* **Google Maps SDK & Maps Compose**: Visualização avançada de mapas e marcadores.
* **Firebase Firestore**: Base de dados em tempo real para a partilha comunitária e sistema de reporte de pontos.
* **Coroutines & Gson**: Processamento assíncrono e persistência de dados locais.
